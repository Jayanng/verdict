# Web app

Landing page and app for Verdict.

- Landing and how-it-works pages.
- Walletless simulation of the full dispute path, mirroring the template
  rules.
- Live path via Sapient on Esmeralda.
- Dispute proof pages: draw inputs with a recompute button, per-item evidence
  hash checks, panel, commits, reveals, ruling, settlement transaction, and
  the escrow's caller rule readable on-chain.
